# Sheeba — Professional Portfolio Website

## Included
- `index.html` — portfolio page
- `styles.css` — purple/white responsive styling
- `script.js` — mobile navigation
- `assets/profile.jpg` — uploaded profile photo
- `assets/Sheeba_Resume.pdf` — resume download
- `README.md` — setup and publishing instructions

## Preview
Extract the ZIP completely, then open `index.html` in a browser. Keep all files and folders together as shown above.

## Publish with GitHub Pages
1. Create a public GitHub repository named `sheeba-portfolio`.
2. Upload the contents of this folder (not the containing folder itself), keeping `index.html`, `styles.css`, and `script.js` at the repository root.
3. Ensure the `assets` folder is also at the repository root.
4. Open Settings → Pages.
5. Select Deploy from a branch, branch `main`, folder `/(root)`, and save.
6. Wait for GitHub Pages to show the published URL.

## Personal details
The email and LinkedIn links are prefilled from the supplied resume. Confirm they are correct before publication. Do not publish confidential employer/client data.
